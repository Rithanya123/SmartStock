# SmartStock
simple inventory managment system in java

## features
- add products (general and grocery)
- view all inventory sorted by id
- smart restock alert - tells u how much to reorder
- binary search for fast product lookup
- insertion sort to keep things in order

## how to run
```
javac Main.java
java Main
```

## types
- GeneralProduct - 5% tax
- GroceryProduct - no tax
